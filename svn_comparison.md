### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это лёгкий указатель на определённый коммит. При создании ветки Git не копирует файлы проекта, поэтому операция выполняется быстро и практически не занимает дополнительного места.

В SVN ветвление  выполняется через копирование каталога в репозитории.

### 2. Можно ли в SVN сделать коммит без интернета? Почему?

В стандартной модели SVN сделать коммит без подключения к серверу нельзя, потому что SVN использует централизованный репозиторий.



### 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может быть предпочтительнее в проектах, где требуется централизованная система контроля версий и единый сервер. Это может быть актуально для некоторых корпоративных проектов, особенно если существующая инфраструктура уже построена на SVN.
